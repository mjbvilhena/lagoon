Open questions

  • Navigation chrome. A Material 3 navigation bar has Home, Search, Inbox, Topics, and Settings. Upcoming is a button on the Home app bar. Pending suggestions is a button on Inbox. Back is the app-bar arrow. From Home, back shows the launcher. The file draws none of these.
  • Settings order follows the wireframe. Change passphrase and Set a new passphrase are extra rows under Trash, because the file does not say where those screens open.
  • Passphrase guidance on setup: “Choose a passphrase of 12 to 128 characters that you do not use anywhere else.” The loss warning states the facts from the passphrase wireframe: the key is derived from the passphrase, forgetting it and losing the device means the content is lost, uninstall or clear storage destroys the Keystore copy, and losing the signing key forces a reinstall that destroys that copy too.
  • Undo snackbar duration is 8 seconds. The words beside Undo are “In trash”.
  • The fog is a grey-green blur with no text and no page content.
  • Dynamic color, when on, uses light accent #6750A4 with white on it, and dark accent #D0BCFF with black #000000 on it. Teal stays the accent while dynamic color is off.
  • The launcher icon is a teal rounded square and a simple wave. It is not final art.
  • Type is the browser system-ui font.
  • Clock warning text, only in that jumped state: “This phone's clock does not match Drive.” No threshold is applied.

Restore conflict

Trash shows Restore, as the Trash wireframe, the Copy table, and approved US-66 require. A later Copy sentence says no screen uses Restore. Backup Restore, Back up now, and a last-backup time are not shown. Delete forever, Delete now, and Empty trash are not shown: the file and US-66 say v1 does not have them.

Other placeholders

  • Light surfaces are #F7F6F4, #EEEFED, and #E4E8E6. Dark surfaces are #101211, #1C1F1E, and #262928. On-surface text is #1A1C1B in light and #E3E3E1 in dark. Text on #0F766E is white. Text on #2DD4BF is #003731. A dark snackbar action uses #2DD4BF so #0F766E is not drawn on a dark surface.
  • A status bar and a gesture handle are drawn. The clock reads 09:41. A lock icon stands in for FLAG_SECURE. Its accessible name is “Screen capture blocked”.
  • Corner radius, spacing, and 48px targets follow common Material 3 sizes.
  • Sample titles, notes, tags, dates, sources, URLs, devices, topics, and quotes are synthetic. Dates use YYYY-MM-DD. Type words are Note, Link, Image, and PDF. Reminder and expiry markers use those words plus the date. This month's topic calls start at 3.
  • The demo vault passphrase is island-ferry-2026. The common-password check uses a short sample list, not the real bundled list. Refusal sentences are “Use 12 to 128 characters.” and “That passphrase is too common.” If the two new fields differ, the sentence is “The new passphrase does not match.” A wrong passphrase shows “Wait, then try again.” and the remaining seconds.
  • After a normal passphrase change, the sentence is “Zips you already exported still open only with the old passphrase.”
  • Low memory: “This phone cannot allocate 65536 KiB, so a vault cannot be created.” Decline after a waiting share: “Nothing was saved.” Decline with no share: “No vault was created.”
  • Share samples on the sheet are Link, Text, Image, PDF, Empty text, file URI, FileProvider, Over 20 MiB, Not a PDF, Repeat link, Two matches, and Trash match. Refusals use “Nothing was saved.” and a button OK. A shared link with no page title yet uses the URL as its title, at most 120 characters. URL matching follows the US-49 normalisation cases. A token-looking URL is one whose query contains token, access_token, or key.
  • Home filters are menus for type, tag, source, and date. An empty vault hides them. A miss or an empty filter has no sentence. Search shows no rows until there is a query. The Home app bar also has Camera and Add.
  • Add note, Add a URL, and Edit use those names in the app bar. An empty URL shows “A URL is required.” Tags on Edit are a comma-separated field. Add date offers one reminder or one expiry, default time 09:00. The first date asks “Allow Lagoon to send notifications?” with Allow and Don’t allow.
  • The affirmative control on “Send N earlier items for topics?” is Yes. No is the default. N is the count of ordinary items with no topic provenance.
  • Disconnect and delete uses the action name as the title. The body is “This lasts only if every other phone is signed out first, because forgotten-installs files are removed too.” Confirm and Cancel follow. There is no success sentence.
  • Export zip and Import zip open a file sheet and then close. Sign-in is a sheet for miguel@example.com and the Drive app-data grant. The grant line is “Allow Lagoon to use its Drive app data folder.”
  • In-app notices that are not the Undo or repeat snackbars use a dialog. The passphrase-reset banner is on Home. Dropped edit, removed files, and lost edits are dialogs.
  • Full-screen pages can be swiped, pinched, scrolled, or stepped with the arrow keys, plus, and minus. A page count is shown. Close is the only named control. Brightness is drawn as a white window.
  • A locked PDF shows the story mark “text not extracted” on the item, and “This PDF is password-protected.” if full screen is requested. Open leaves the app for the viewer. No password field is shown.
  • The biometric prompt accepts a tap on the mark, or Use PIN and any 4 digits. API 26–29 is not a separate device setting here. Use PIN is always available.
  • Loading is a circular indicator during passphrase accept, preview fetch, sign-in, camera confirm, and a returning-phone rebuild, and on the Home loading jump. Its accessible name is “Loading”.
  • API 30 is only the screen jump that hides Dynamic color. There is no in-app API control.
  • The link viewer does not load a page. It shows the host on an empty surface.
  • No camera app uses the sentence “No camera app.” Cancel stores nothing.
  • Quick-add Add note writes the personal note under YYYY-MM-DD. Choosing a tag adds it to the new item.
  • Which-item uses the wireframe label dismiss. When every match is in trash, Restore is on each of those rows.
  • Empty topic, empty inbox, and empty trash have no extra sentence unless the file gives one. Topic list empty uses “There are no topics.” Topic detail empty uses “Nothing is linked.”
  • A sensitive topic link shows Sensitive and hides the title, note, and quote until unlock.
  • Try again and No topics are dialogs on the item. Without a topic key, Get topics shows the missing-key sentence.
  • Returning-phone heading is “Enter the passphrase” and the confirm control is Continue. Cancel or a wrong passphrase discards nothing.
  • Notification shade and the launcher are drawn system surfaces. Other launcher icons are Phone, Messages, and Camera. Messages opens the share sheet.
