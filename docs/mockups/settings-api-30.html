Text recognition

The image and the recognized text stay on this phone. They are not sent to Google. ML Kit sends usage and diagnostic metrics to Google over HTTPS. ML Kit does not transfer them to third parties. ML Kit may contact Google for model updates and bug fixes. This app has no switch to turn those metrics off. The metrics are: device information and ML hardware accelerators, package name and version, per-installation identifiers, performance metrics, API configuration, input and output size, feature version, event types, and error codes.
